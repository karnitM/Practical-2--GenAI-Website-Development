# FEDev---squid-game-Sveltkit-wbesite

This is a 2-page website about the Squid Game Netflix TV series
- `/` home page
- `/about` about the series

It is a SvelteKit project.


## Stage 2 – Character Pages (Using GenAI for CSS Design)

For Stage 2, I created a new **Characters** section in SvelteKit.  
I built all of the SvelteKit pages myself, including:

- `/characters` index page  
- `/characters/001` – Oh Il-nam  
- `/characters/067` – Kang Sae-byeok  
- `/characters/456` – Seong Gi-hun  

### How GenAI was used
I used GenAI specifically to help with the **CSS design** of the character pages.  
The AI assisted with:

- Improving the layout and styling  
- Creating a cleaner card-style design  
- Suggesting colour choices, spacing, and image alignment   

### What I did myself
- I created all the SvelteKit pages  
- I wrote the routing and structure  
- I added the navigation link  
- I implemented the pages based on the AI’s CSS suggestions
